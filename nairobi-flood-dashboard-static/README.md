# Nairobi Flood Dashboard Static

A static, responsive dashboard preview based on the Nairobi urban flood risk design. It uses plain HTML, CSS, and JavaScript; no backend, build step, packages, or database are required.

## How to use

Open `index.html` in a browser. Use the sidebar or Explore links to navigate the page. Select **Generate report** to print the dashboard or save it as a PDF.

## Files

- `index.html` - dashboard content and navigation
- `styles.css` - responsive dashboard and print styles
- `script.js` - in-page navigation and print action

The values shown are static illustrative examples, not live data. The backend team can later connect the dashboard to production data.
